# NOR-212
Phase 2b bivalent GI.1/GII.4c norovirus vaccination in infants and serologic evidence that pre-existing immunity is required for broad GII.4 neutralization 

Data Sharing Plan

De-identified ID50 values by visit/day for NOR-212, NOR-202, NOR-215 participants, and vaccinated mice, and the statistical analysis STATS code utilized in the manuscript, “Phase 2b bivalent GI.1/GII.4c norovirus vaccination in infants and serologic evidence that pre-existing immunity is required for broad GII.4 neutralization,” are included in these files. For NOR-202, the data file also includes participant age and dose. The clinical protocols and statistical analysis plans for NOR-212, NOR-202, and NOR-215 are available at ClinicalTrials.gov. Data are from a sponsor-funded clinical trial; any restrictions on data availability are consistent with applicable legal and ethical obligations to protect participant privacy.
